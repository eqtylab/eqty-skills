# eqty-manifest

The **read** side: parse, verify and report on an existing EQTY lineage
manifest. The skill declared in `SKILL.md` is named `eqty-manifest`, and this
directory is named to match so it can be installed as a skill directly.

The **write** side — instrumenting a repo so it emits a manifest — is the
separate `eqty-instrument` skill, one directory over.
